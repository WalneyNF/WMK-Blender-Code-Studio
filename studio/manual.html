Objetivo: você já programa, mas não conhece modelagem 3D? Aqui aprende a construir objetos do Blender com bpy, usando templates e editando Python. Comece numa cena nova para não alterar trabalhos importantes.

1. O que estamos construindo?

O WMK Blender Code Studio é uma interface web complementar ao Blender, não substitui o programa. O Blender gera e renderiza as malhas; a aplicação ajuda a escolher modelos, mudar parâmetros, estudar código Python e enviar templates autorizados pelo MCP local.

2. Instalação no Windows (XAMPP)

  1. Instale Blender e XAMPP (Apache com PHP 8.1+ e extensão sockets).
  2. Extraia a pasta WMK-Blender-Code-Studio para C:\xampp\htdocs\.
  3. Inicie Apache e abra http://localhost/WMK-Blender-Code-Studio/.
  4. Para executar pelo MCP, abra o Blender, habilite seu add-on MCP e confirme que ele escuta apenas localhost:9876.
  5. Abra a aba Conexão e clique em Testar conexão. Para apenas copiar/baixar código Python, o MCP não é necessário.

Observação: o Monaco carrega de uma CDN e exige internet para mostrar o editor avançado. Sem internet, o aplicativo tem um editor de texto simples como alternativa.

3. Primeiro teste: cubo

  1. No Blender, salve seu projeto atual e crie um arquivo vazio usando File → New → General.
  2. No Studio, escolha o template Cubo e abra Editor & parâmetros.
  3. Altere largura, altura e outros parâmetros disponíveis, observando como o Python é regenerado.
  4. Escolha Copiar código, depois vá ao Blender → Scripting → New, cole e execute com Alt+P. Alternativamente, use Executar template autorizado com a confirmação marcada e a ponte ativa.
  5. No Outliner do Blender, localize a coleção que começa por WMK_LAB_.
import bpy
bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 1))
obj = bpy.context.object
obj.name = "WMK_Meu_Primeiro_Cubo"
print(obj.name, tuple(obj.location))

4. Como o Python do Blender funciona

O Blender inclui um interpretador Python próprio. A biblioteca bpy controla objetos, coleções, cenas, animações, materiais, modificadores, câmeras e exportação. O módulo mathutils oferece vetores, matrizes e quaternions. bpy.ops executa operações semelhantes às feitas nos menus, enquanto bpy.data acessa diretamente blocos de dados.

5. Python do Windows × Python do Blender

O Python instalado no Windows e o Python embutido no Blender são ambientes distintos. Você pode executar scripts dentro do Blender pela aba Scripting, pelo Python Console ou em processos do Blender em modo background. Uma instalação Python convencional em geral não permite import bpy sem instalar uma distribuição compatível; para iniciantes, a forma mais confiável é executar dentro do Blender.

6. Posso usar bibliotecas Python comuns?

Sim, com cuidados. Bibliotecas puramente Python frequentemente funcionam quando compatíveis com a versão do interpretador embutido. Dependências com código nativo precisam corresponder à versão do Python, ao sistema operacional e à arquitetura do Blender. Evite instalar pacotes indiscriminadamente na instalação principal.

# No Python Console do Blender:
import sys
print(sys.version)
print(sys.executable)

# Biblioteca padrão: disponível sem instalar
import json, math, pathlib, random

Para instalar pacotes adicionais use preferencialmente um ambiente de teste e o interpretador informado por sys.executable, com pip quando suportado. Exemplo no PowerShell, substituindo pelo caminho real obtido no Blender:

& "CAMINHO_DO_PYTHON_DO_BLENDER" -m pip install nome-do-pacote

Antes de usar bibliotecas externas, avalie licença, segurança e compatibilidade. Para tarefas como geração de malha, normalmente bpy e mathutils já são suficientes. Num projeto público, documente as versões e fixe dependências.

7. Templates e parâmetros

Os 41 modelos ficam em templates/catalog.json. Cada entrada contém identificador, categoria, nível, descrição, parâmetros, aula resumida e corpo Python. As funções compartilhadas, como cube, cyl e mat, ficam em templates/common.py.txt. O Studio combina essas peças e gera um script legível. Você pode duplicar templates e editar seus próprios modelos pelo Monaco, mas a ponte PHP não executa código livre por segurança.

8. Articulações, animações e exportação

Uma junta mecânica costuma usar um objeto controlador (Empty), com peças filhas. O pivô precisa estar no centro físico da rotação. Animações podem ser criadas com keyframe_insert. Para exportar GLB, use Blender → File → Export → glTF 2.0, revisando eixos, materiais, modificadores e animações. O Studio não afirma validar GLB automaticamente.

9. Comunicação com MCP e segurança

A interface faz uma chamada local POST a api/bridge.php. O PHP valida o ID e os parâmetros de um template original, constrói código a partir do catálogo do servidor e envia a mensagem {"type":"execute_code","params":{"code":"..."}} ao addon pela porta TCP 9876. Scripts livres no Monaco ou templates personalizados não são enviados pela ponte. Execute apenas conteúdos confiáveis e faça backup de arquivos .blend antes dos testes. Nunca exponha a ponte via internet e não altere o bind local do addon.

10. Projetos e DNA

Em Projetos & DNA você cria cadastros por robô ou jogo, associa templates utilizados e exporta o histórico JSON. Templates próprios e projetos são armazenados no localStorage do navegador. Exporte backups periodicamente: apagar dados do navegador pode remover esses registros.

11. Exercícios: do básico ao avançado

  1. Primeiro contato: cubo, cilindro, esfera, nome e coordenadas. Objetivo: compreender cena e transformação.
  2. Materiais: duplicar o cubo e trocar prata por roxo na função mat. Objetivo: entender nós PBR.
  3. Geometria: executar Bevel, Array e Mirror em cópias de teste. Objetivo: conhecer modificadores não destrutivos.
  4. Mecânica: montar junta, pistão e engrenagem. Objetivo: estudar objetos independentes e pivôs.
  5. Construção: gerar casa, torre e ponte. Objetivo: peças modulares com proporções consistentes.
  6. Jogos: construir robô estilizado, herói low-poly e vila procedural. Objetivo: organizar coleções e performance.
  7. Projeto final: escolher três templates, modificar, salvar o DNA e exportar um GLB pelo Blender.

12. Problemas frequentes

O botão Executar não conecta

Verifique se Apache está ativo, extensão sockets carregada, Blender aberto com addon conectado e porta 9876 livre. Confira também se o projeto está sendo aberto por localhost em vez de file://.

Monaco não carrega

Confira internet, console do Chrome e bloqueio à CDN. Use o editor alternativo ou hospede o Monaco localmente numa versão posterior.

Alterei um template e o Blender não usa meu código

Por segurança, a ponte executa apenas o código original do catálogo e parâmetros validados. Baixe o Python modificado e execute manualmente no Blender, após revisar o script.

Objetos aparecem em posições inesperadas

Confira localização, rotação, escala, objeto ativo, coordenadas locais versus globais e pivôs. Use uma cena nova para isolar o teste.

13. Como criar seu próprio template

  1. Na biblioteca, clique em Duplicar para preservar o original.
  2. Abra o editor, altere somente o corpo do script entre os marcadores INICIO_TEMPLATE_WMK e FIM_TEMPLATE_WMK.
  3. Use funções auxiliares como cube, cyl e mat para criar geometria.
  4. Clique em Salvar template e faça Backup JSON.
  5. Para testar código livre, baixe o .py, abra uma cena de testes no Blender e execute no workspace Scripting. Templates pessoais não são enviados pelo botão MCP nesta versão.

Atenção: a edição livre de corpo Python é destinada a quem revisa o código. Nunca execute scripts recebidos de desconhecidos sem inspeção.
