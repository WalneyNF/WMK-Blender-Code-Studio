Conexão Blender MCP

Ponte PHP local entre XAMPP e o complemento do seu fork.

Como funciona

Este aplicativo envia uma solicitação para api/bridge.php no XAMPP. O PHP conversa com o complemento Blender MCP por socket TCP no endereço 127.0.0.1:9876.

HTML + Monaco→PHP local→Blender MCP→Blender

Aguardando teste.

Segurança

A ponte executa templates validados e, somente com aprovação explícita e token de sessão, o código livre atual do editor. Python tem acesso total ao computador: revise o script, salve um backup do .blend, mantenha o MCP em localhost e nunca publique a pasta api/ na internet.
