Estado: protótipo v0.1. O sistema gera uma casa simplificada a partir de medidas explícitas. Não reconhece automaticamente fotografias ou plantas técnicas, não fornece levantamento confiável e não substitui projeto arquitetônico/estrutural ou aprovação legal.

1. O que permite construir?

Uma laje retangular, paredes externas com portas/janelas como vãos geométricos, divisórias internas retilíneas e materiais básicos. Cada objeto gerado possui dimensões reais e propriedades personalizadas visíveis no Blender. A coleção e o DNA JSON facilitam analisar a cena por Python.

2. Como usar pelo painel HTML

  1. Abra index.html no navegador. Não requer XAMPP, IA ou Three.js.
  2. Configure largura, comprimento, pé-direito, espessura das paredes e espessura da laje utilizando sliders.
  3. Ajuste as portas e janelas (lado, posição, largura, altura e peitoril). A prévia 2D atualiza imediatamente.
  4. Clique em Baixar planta.json. Renomeie o arquivo baixado para planta-exemplo.json, se necessário.
  5. Guarde o JSON na mesma pasta de gerar_casa.py ou defina seu caminho absoluto na variável JSON_PATH.

3. Executar o Python no Blender

  1. Abra o Blender e salve uma cópia da cena antes do teste.
  2. Vá até Scripting → Text Editor → Open, selecione gerar_casa.py.
  3. Se você usa Run Script no editor e o JSON não é encontrado, configure JSON_PATH explicitamente. Caso contrário, o script usa a planta de exemplo embutida e avisa no console.
  4. Execute com Alt+P.
  5. Abra o Outliner e localize a nova coleção WMK_ARQUITETURA_....
  6. Selecione uma parede e, em Object Properties → Custom Properties, inspecione wmk_width_m, wmk_depth_m, wmk_height_m e wmk_kind.

4. Entendendo o JSON

{
  "schema": "wmk.architecture.v0.1",
  "unit": "m",
  "width": 10,
  "depth": 8,
  "height": 2.8,
  "wall_thickness": 0.18,
  "slab_thickness": 0.16,
  "openings": [
    {"id":"PORTA_ENTRADA","side":"south","offset":1.6,
     "width":0.95,"height":2.15,"sill":0}
  ],
  "partitions": [
    {"id":"DIVISA_QUARTO","start":[4.4,0.18],"end":[4.4,7.82]}
  ]
}
PropriedadeInterpretação
width, depthLargura (X) e comprimento (Y) da construção em metros
heightAltura das paredes, a partir do topo da laje (Z=0)
wall_thicknessEspessura nominal das paredes
offsetDistância do início da parede até o começo do vão
sillAltura inferior do vão — zero significa abertura até o piso
partitionsLinhas (X,Y) que determinam divisórias sem portas, por enquanto

5. Como o Blender cria os vãos?

O programa não pinta uma porta sobre uma parede sólida. Ele divide cada parede em trechos horizontais e, onde existe abertura, gera somente os blocos abaixo e acima do vão. Assim é possível passar pela porta porque a geometria realmente deixa um espaço vazio.

6. Consultar medidas por código

import bpy
for obj in bpy.data.objects:
    if obj.get("wmk_kind") == "wall":
        print(obj.name, obj.get("wmk_width_m"), "m")

O sistema também guarda o JSON original em um bloco de texto interno do Blender, com o nome da coleção seguido de _DNA.json.

7. Medidas precisas: cuidados importantes

As paredes externas estão centralizadas nos eixos de contorno do retângulo (não nas faces internas). Portanto, width=10 representa a distância entre os eixos de referência das paredes opostas, e não automaticamente a largura interna útil. Os cruzamentos de paredes e divisórias podem se sobrepor geometricamente. Antes de usar para levantamento quantitativo ou construção, deverão ser implementadas as convenções dimensionais, os encontros de paredes e as tolerâncias.

8. Imagem de planta baixa: etapa futura

Uma imagem ou PDF não traz medidas confiáveis por si só. Para reconstrução assistida, primeiro precisamos calibrar escala com pelo menos uma dimensão conhecida; depois identificar paredes, cotas, portas e janelas usando visão computacional/OCR e exigir confirmação manual. O fluxo automatizado de imagem para 3D ainda não está implementado.

Faça uma residência de 12 × 9 m com pé-direito de 3 m. Acrescente uma porta de 0,90 × 2,10 m e janela de 1,50 × 1,20 m com peitoril de 1 m. Exporte o JSON, gere o modelo no Blender e confira pelo menos três medidas nas Custom Properties.
