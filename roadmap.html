WMK • BLENDER CODE STUDIO

Roadmap de evolução

Dois projetos complementares, gratuitos e abertos: o fork MCP for Blender e a IDE Web WMK Studio. O objetivo é ensinar modelagem 3D com Python, facilitar a integração com IAs e criar assets para jogos. As tarefas têm status verificável; protótipos não são apresentados como concluídos. Abrange objetos, Outliner, materiais, rig, animações, Meshy/GLB, análise de imagens, integração de IAs e exemplos de veículos.
